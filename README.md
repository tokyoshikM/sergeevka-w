# Сергеевское водохранилище — лендинг

Одностраничный сайт на HTML и CSS. Не требует сборки или установки зависимостей.

## Как опубликовать через GitHub Pages

1. Создайте новый репозиторий на https://github.com/new (например, `sergeevskoye-reservoir`).
2. Загрузите в репозиторий файл `index.html` (можно перетащить его на странице репозитория через **Add file → Upload files**).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, нажмите **Save**.
6. Подождите минуту или несколько. GitHub покажет адрес сайта вида:
   `https://ВАШ-ЛОГИН.github.io/sergeevskoye-reservoir/`

## Как сделать QR-код

После публикации скопируйте точный адрес GitHub Pages и создайте QR-код, который ведёт на этот адрес. Не используйте адрес репозитория вместо адреса сайта с окончанием `github.io`.

## Примечание

Фотографии загружаются с Unsplash через интернет. Для фактической точности замените их своими фотографиями водохранилища, если они у вас есть.
